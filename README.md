# Projeto Juci Buffet

## Sobre o projeto

Este projeto foi desenvolvido com o objetivo de criar uma planilha inteligente para gestão financeira e formação de preços de um buffet.

O arquivo permite calcular os custos de produção, despesas operacionais e margem de lucro, auxiliando na precificação dos serviços de forma estratégica.

---

## Objetivos

- Organizar custos do buffet
- Automatizar cálculos
- Padronizar formação de preços
- Facilitar tomada de decisão
- Reduzir erros em cálculos manuais

---

## Ferramentas utilizadas

- Microsoft Excel
- Fórmulas Avançadas
- Tabelas
- Automações
- Formatação Condicional

---

## Funcionalidades

✔ Cadastro de produtos

✔ Controle de ingredientes

✔ Cálculo automático dos custos

✔ Inclusão de despesas operacionais

✔ Cálculo de frete

✔ Pró-labore

✔ Margem de lucro

✔ Formação automática do preço de venda
